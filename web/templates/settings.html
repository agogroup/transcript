使い方ガイド

1. APIキーの取得

  1. OpenAI Platformにアクセス
  2. アカウントにログイン（または新規登録）
  3. 「API Keys」メニューから新しいAPIキーを作成
  4. 生成されたAPIキーをコピー

2. APIキーの設定

  1. 上記フォームにAPIキーを入力
  2. 「APIキーを保存」ボタンをクリック
  3. 保存が完了したら、文字起こしページへ移動

3. 文字起こしの実行

  1. 音声ファイルをアップロード
  2. 必要に応じてオプションを設定
  3. 「文字起こしを開始」ボタンをクリック
  4. 完了したら結果をダウンロード

料金について

OpenAI Whisper APIの料金は、音声の長さに基づいて課金されます。

  • 料金: $0.006 / 分
  • 例: 1時間の音声 = 約$0.36

詳細はOpenAI Pricingをご確認ください。
